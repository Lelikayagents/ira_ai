## 📘 2. Грамматика (20 мин)

### 2.1 Как читать немецкий (самое важное для русскоязычных)

| Буквы | Читаются | Пример |
| --- | --- | --- |
| `w` | **в** | Wasser — «вассер» |
| `v` | **ф** (обычно) | Vater — «фатер» |
| `z`, `tz` | **ц** | Zeit — «цайт» |
| `j` | **й** | ja — «йа» |
| `s` перед гласной | **з** | Sofa — «зофа» |
| `ß`, `ss` | **с** | Straße — «штрассе» |
| `sch` | **ш** | Schule — «шуле» |
| `sp-`, `st-` в начале слова | **шп-, шт-** | Spiel, Stuhl |
| `ch` после a, o, u, au | **х** | Buch, Nacht |
| `ch` после i, e, ä, ö, ü | мягкое **хь** | ich, Milch |
| `ei` | **ай** | Wein — «вайн» |
| `ie` | долгое **и:** | Liebe — «ли:бе» |
| `eu`, `äu` | **ой** | Freund — «фройнд» |
| `ä` | **э** | Käse — «кэ:зе» |
| `ö` | как во франц. *peu* (губы «о», язык «э») | schön |
| `ü` | губы «у», язык «и» | Übung |

**Ловушки:** в конце слова звонкие оглушаются (Tag — «так», Hund — «хунт»); все существительные — **с большой буквы**.

### 2.3 Первые предложения и порядок слов 📖
Книга называет места в предложении **Position I – Position II – … – ENDE**. Запомните главное правило немецкого:

> **Спрягаемый глагол всегда на втором месте (Position II).**

| Position I | Position II | дальше |
| --- | --- | --- |
| Ich | heiße | Anna. |
| Ich | komme | aus Russland. |
| Ich | wohne | in Moskau. |
| **In Moskau** | **wohne** | ich. |
| **Aus Russland** | **komme** | ich. |

Если на первое место вышло другое слово, **глагол всё равно остаётся вторым**, а подлежащее встаёт после него.

### 2.4 du или Sie?
- **du** — друзья, семья, коллеги «на ты», дети. Приветствие: `Hallo!`
- **Sie** (всегда с большой буквы) — незнакомые, клиенты, деловая переписка. Приветствие: `Guten Tag, Herr Müller.`
- В профессиональной среде по умолчанию — **Sie**, пока собеседник не предложит «du».

## 🧠 3. Новые слова (15 мин) — 17 единиц

| Немецкий | Русский | Пример |
| --- | --- | --- |
| **Hallo!** | привет | Hallo, ich heiße Anna. |
| **Guten Morgen!** | доброе утро | Guten Morgen, Frau Meier! |
| **Guten Tag!** | добрый день | Guten Tag, Herr Müller! |
| **Guten Abend!** | добрый вечер | Guten Abend! |
| **Gute Nacht!** | спокойной ночи | ⚠️ говорят при прощании перед сном, не при встрече |
| **Tschüss!** | пока | Tschüss, bis morgen! |
| **Auf Wiedersehen!** | до свидания | вежливо/формально |
| **Danke!** | спасибо | Danke schön! |
| **Bitte!** | пожалуйста (и «не за что») | Danke! – Bitte! |
| **Entschuldigung!** | извините | чтобы привлечь внимание |
| **Wie geht's?** | как дела? | Wie geht's? – Gut, danke. Und dir? |
| **Wie geht es Ihnen?** | как ваши дела? (формально) | Gut, danke. Und Ihnen? |
| **Freut mich.** | приятно познакомиться | Ich heiße Paul. – Freut mich! |
| **der Name, -n** | имя/фамилия | Mein Name ist Anna. |
| **der Vorname, -n** / **der Nachname, -n** | имя / фамилия | Mein Vorname ist Anna. |
| **heißen** | называться | Ich heiße Anna. |
| **kommen (aus)** | приходить; быть родом из | Ich komme aus Russland. |
| **wohnen (in)** | жить (проживать) | Ich wohne in Moskau. |
| **Herr / Frau** | господин / госпожа | Herr Müller, Frau Meier |

*Приём:* для каждого слова скажите вслух предложение про себя (а не только перевод).
