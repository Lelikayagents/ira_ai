# Шаблон ежедневного урока

Каждое утро: взять из `plan/` блок текущей даты, собрать из него урок по этому шаблону и сохранить как `lessons/ГГГГ-ММ-ДД.md`. Язык объяснений — русский, примеры — немецкий (с переводом новых слов).

```
# 🇩🇪 День N из 67 · день недели ДД.ММ.ГГГГ · Тема

⏱ ≈75 мин: 🔁10 · 📘20 · 🧠15 · ✍️20 · 🗣10

## 🔁 1. Повтор (10 мин)
Слова дней N-1, N-3, N-7, N-14, N-30 (по 6–8 единиц из каждого дня) + Fehlerliste.
Формат: список «рус → нем.» (закройте правую колонку) + 5 коротких фраз-переводов.

## 📘 2. Грамматика (20 мин)
Объяснение по-русски: правило → таблица → 5–8 примеров → «ловушки».
(📖 — отсылка к учебнику со страницей, если есть.)

## 🧠 3. Новые слова (15 мин)
12–18 единиц: артикль, мн. число, перевод, пример-предложение. 
Совет по запоминанию (ассоциация / цепочка / картинка).

## ✍️ 4. Упражнения (20 мин)
3 задания возрастающей сложности (узнать → заполнить → составить). 10–20 пунктов.

## 🗣 5. Активное (10 мин)
Сказать вслух / написать 3–8 предложений по заданию. Если пришлёте — проверю.

## 🎧 6. Бонус (по желанию, 10 мин)
Аудирование / чтение по теме.

## ✅ Ключи
Ответы ко всем упражнениям.

## 🔜 Завтра
Тема + «сегодня можно вспомнить заранее: …».
```

Правила:
- Каждый урок — самодостаточный, ≤ 1 экрана на раздел.
- Суббота: тест (20–30 заданий + 20 слов) + письмо; ключи — отдельно внизу.
- Воскресенье: ≈ 35 мин, без новой грамматики.
- Если день пропущен: не навёрстывать, продолжить с даты по календарю; пропущенное слово/тема — в `progress.md` и повтор в воскресенье.
